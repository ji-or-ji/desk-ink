## `desk-eink-info/` 怎么读

### 先读这两份

| 文档 | 用途 |
|---|---|
| `项目现状与下一步.md` | **回到状态**：现在到哪了、下一步做什么 |
| `checklist.md` | 硬件模块核对手册（打样前后对着查） |

### 设计文档

| 文档 | 管什么 |
|---|---|
| `ui-spec.md` | 界面上显示什么、怎么排（含坐标） |

| `protocol.md` | PC ↔ ESP32 的消息格式 |
| `architecture.md` | 固件模块划分与任务 |
| `driver-api.md` | 各模块的 C API |
| `font-plan.md` | 字库方案 |
| `classisland-link.md` | 课表数据从哪来（IPC 接口） |
| `pc-tool.md` | PC 端工具的技术选型 |
| `software-notes.md` | 踩坑记录与实测结论（**排查前先看这份**） |

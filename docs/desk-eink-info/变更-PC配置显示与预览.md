## 二、A. 只读展示设备配置

### 2.1 要接收的消息（设备 → PC）

设备会在**上电握手后**和**本地改配置后**各发一次：

```json
{"t":"cfg","refresh":1,"pomo_focus":25,"pomo_break":5,
 "rotate":1,"art_mode":0,"bar_mode":0}
```

| 字段 | 取值 |
|---|---|
| `refresh` | 0 自动 / 1 常规 / 2 静默 |
| `pomo_focus` | 15 / 25 / 45 |
| `pomo_break` | 5 / 10 |
| `rotate` | 0 关 / 1 开 |
| `art_mode` | 0 全屏 / 1 小窗 |
| `bar_mode` | 0 实心 / 1 反色 / 2 反色自适应 |

### 2.2 要改的地方

| 文件 | 改什么 |
|---|---|
| `Models/Protocol.cs` | 加 `ConfigMessage`（六个 `int`，`[JsonPropertyName]` 对齐上表） |
| 收行分发处 | 加一个 `t == "cfg"` 分支，更新内存里的设备配置快照 |
| `Pages/SettingsPage.xaml` | 加「**设备配置**」区：六行只读展示 + 「最近同步」时间戳 |

### 2.3 展示要求（三条都是硬要求）

**① 未连接 / 尚未收到 `cfg` 时显示「—」，不要显示默认值。**

显示默认值等于撒谎——你会以为设备就是那个设置。

**② 值 → 文案必须与设备端 `config_value_label()` 一字不差：**

| 项 | 文案 |
|---|---|
| 刷新档位 | 自动 / 常规 / 静默 |
| 番茄钟专注 | `25 分`（数值 + 一个空格 + 分） |
| 番茄钟休息 | `5 分` |
| 小窗轮换 | 开 / 关 |
| 插画显示 | 全屏 / 小窗 |
| 信息条 | 实心 / 反色 / 反色自适应 |

**③ 这一区是只读的。** 不要加输入控件、不要加「保存到设备」按钮。

## 三、B. 预览加「合成模式」下拉

现在预览只是一张 1-bit 位图。加一个下拉，切换**合成后的样子**：

| 选项 | 画什么 |
|---|---|
| 仅插画 | 现在的行为 |
| 全屏 + 实心条 | 400×300 铺满 + 顶部 32px 黑条白字 |
| 全屏 + 反色条 | 同上，条内取反 |
| 全屏 + 反色自适应 | 同上，逐段自适应字色 |
| 小窗模式 | 插画缩到 134×200，画在右列小窗位置 |

**硬要求：必须用设备真字库。**

把 `software/font/font16_simsun.bin`（131 KB）和 `ascii8x16.bin`（1.5 KB）随工具打包，
按 `F16B` 格式取字模（magic + `uint16 N` + `uint16 codes[N]` + 每字 32 字节，MSB 在左）。

> 用系统字体渲染的预览是**假的**：字宽不同，信息条长度就不同。

**下拉默认值**：跟随 A 上报的 `art_mode` / `bar_mode`；未收到上报时才回落到「仅插画」。

**信息条内容用占位值即可**（如 `09:40` / `第3节 数学`）。预览的目的是看**版面和可读性**，
不是看数据对不对。

**参考实现**：`tools/render-preview.ps1` 已经把这套做完了（同算法、同字库），
`-Bar solid|invert|auto` 三个取值就是上面三种。可直接对照。

**不要做的**：别预览 POMO / TODO_NAV / TODO_EDIT / MENU / CONFIG。
那些没有插画介入，PC 上复刻它们等于把 `ui.c` 抄第三遍。

## 四、⚠️ 硬规则：PC 不得推送配置

这是本次最重要的一条，**写死**：

```
PC 连上 → 设备 hello → 设备 cfg 全量上报 → PC 更新界面
                                               ↑
                                          到此为止，PC 不改设备
```

理由很实际：用户在设备上刚调好的东西，如果 PC 一连上就用自己的存档推下去，
**当场被覆盖**——「设备可脱离 PC 单独配置」这条就废了。

本次是只读，所以 **PC 端根本不该有写入口**。将来要写回是第二步的事，本次不做。

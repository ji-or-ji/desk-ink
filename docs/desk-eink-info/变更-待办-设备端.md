## 二、`todo` 分片

### 2.1 为什么必须分片

单条的 JSON 固定开销就有 **30 字节**（`{"id":1,"done":true,"text":""}`）：

- 8 条即使**文本全空**，也已 **269 字节** > 255
- 装 14 个汉字的满员列表 ≈ **590 字节**

而且现在是**静默丢数据**：`link_send_todo` 里那句 `todo frame full, truncated at item %d` 会截掉后面的条目，
但 `todo` 是**全量覆盖**语义——对面收到残缺列表，会把缺的当成"用户删了"。

`uart_write_line` 对 >255 也只**警告不拒绝**，所以现在会真把超长帧发出去。

### 2.2 发送

`link_send_todo` 改成按片发送：

```json
{"t":"todo","seq":0,"total":2,"items":[{"id":1,"done":true,"text":"英语单词 Unit5"},{"id":2,"done":false,"text":"买电池"}]}
{"t":"todo","seq":1,"total":2,"items":[{"id":3,"done":false,"text":"预习生物第 3 章"}]}
```

- **每片最多 2 条**（2×72 + 外壳 ≈ 186 字节 < 255）
- `total = ceil(count / 2)`
- 片与片之间可以留一点间隔（如 `vTaskDelay(1)`），别把蓝牙缓冲灌爆

### 2.3 接收

`link.c` 里 `MSG_TODO` 的解析改为**分片累加**：

```
收到 seq == 0        → 清空累加缓冲，开始新任务
逐片追加 items
序号跳号             → 丢弃整个任务，等下一次 seq == 0
收齐 total 片        → 整体覆盖本地 todo，再交给 ui
```

累加缓冲用一个静态数组即可：8 条 × `(48+8)` ≈ **450 字节**，RAM 够。

> 参考 `img_begin/chunk/end` 那套的容错写法（`link.c` 里已有"中途收到新 begin 则丢弃旧任务"）。

## 三、勾选接线

### 3.1 `ST_TODO_NAV` 中央短按

现在是这样：

```c
} else if (ev == INPUT_CENTER_SHORT) {
    /* 切换勾选 → 回传 PC（数据层实现后接 link_send_todo） */
    render_state();
    present();
}
```

改成：

```c
} else if (ev == INPUT_CENTER_SHORT) {
    todo_toggle_done(s_todo_cursor);   /* 1. 翻转 done          */
    todo_save_nvs();                   /* 2. 存 NVS（过夜不丢）  */
    link_send_todo(&s_todo_local);     /* 3. 回传 PC（走 2.2 的分片）*/
    render_state();                    /* 4. 重绘               */
    present();
}
```

### 3.2 需要的东西

| 项 | 说明 |
|---|---|
| `s_todo_local` | app 自己持有一份 `todo_list_t`（不能只往 ui 塞，要能改、能回传） |
| NVS 持久化 | 整表存一个 JSON 字符串（key 如 `todo_json`，约 600 字节，NVS 装得下）；开机恢复 |
| 越界保护 | `s_todo_cursor` 要对着**实际条数**夹紧，不是对着 `UI_TODO_MAX`（现在是 `s_todo_cursor < UI_TODO_MAX - 1`，**条数少时会移到空行**） |

> 顺手修掉：现在上下键允许光标移到不存在的条目上（拿 `UI_TODO_MAX` 当上限）。应该用 `count`。

### 3.3 完成后怎么处理

**本次什么都不做——只翻转 `done`，条目继续留在列表里**（绘制层会把它画成勾选状态）。

其他方案（自动清除 / 完成后隐藏）**不做**。理由：自动删除会误伤，而"完成后隐藏"要改绘制层，本次不碰。

## 五、验收

1. 设备上进入待办，按中央键 → 该条**勾上**，再按 → 取消
2. 勾选后**断电再上电**，勾选状态还在（NVS 生效）

5. 条目只有 3 条时，按上/下键**不会**把光标移到空白处

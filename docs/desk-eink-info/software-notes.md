# 桌面墨水屏信息站 — 软件注意事项（按模块索引）

> ⛔ **当做出任何改变底层的内容时，必须翻阅文档（优先级：本地 > 立创 > 其他）**

---

## ESP32-C3 系统基础

- **模组**：ESP32-C3-WROOM-02-N4（4MB Flash）
- **框架**：ESP-IDF v5.x / Arduino-ESP32 均可，建议 IDF 以便精细控制休眠
- **分区表**：默认（app 1.5MB + SPIFFS 1.5MB）够用
- **USB Serial/JTAG 下载口**：GPIO18(USBD−)/GPIO19(USBD+)，共享充电口 USB-C，`idf.py flash -p COMx` 自动进下载模式
- **UART0**（GPIO20/21）被 VG6328A 占用，**不使用** UART0 做日志输出；日志走 USB Serial/JTAG

## 电源管理 — BQ24073 + XC6206

| 注意点 | 说明 |
|--------|------|
| CE 已接 GND | 上电即充电，软件无需操作 |
| /CHG (Pin 9) | 可接 LED 或 GPIO，充电时拉低。可选读 |
| PGOOD (Pin 7) | USB 插入时拉低，可选 GPIO 检测外部供电状态 |

**软件层面：**这部分不需要软件控制，插电自动充。

## 电池电压监测 — MCP3021A3T

| 项目 | 值 |
|------|:----:|
| I2C 地址 | **0x4B**（7-bit） |
| 分辨率 | 10-bit |
| VREF | VDD（3.3V） |
| 分压比 | 2:1（100k+100k），VOUT/2 送入 AIN |

**软件：**
```
raw = i2c_read(0x4B)          // 10-bit ADC 值
v_ain = raw * 3.3 / 1023       // 分压后电压
v_bat = v_ain * 2               // 还原真实电池电压 (~3.0V~4.2V)
```

插 USB 时 VOUT=4.4V，ADC 读数为 ~2.2V × 2 = 4.4V ✅

## RTC 时钟 — DS3231MZ+TRL

| 项目 | 值 |
|------|:----:|
| I2C 地址 | **0x68**（7-bit） |
| SQW 引脚 | → **GPIO 7**（EXT0 唤醒源） |
| 闹钟 | 配置 SQW 为中断输出，唤醒深度休眠的 ESP32 |

**休眠唤醒流程：**
```
1. ESP32 进入深度休眠前：
   - 设置 DS3231 闹钟时间
   - 配置 SQW 为中断模式
   - 调用 esp_deep_sleep_enable_ext0_wakeup(GPIO_NUM_7, 0)
2. 到闹钟时间 → DS3231 拉低 SQW → ESP32 唤醒
3. 唤醒后通过 I2C 读取 DS3231 当前时间
4. 刷新墨水屏 → 再次设置闹钟 → 休眠
```

**VBAT 引脚：**只挂了 10μF→GND，无纽扣电池。掉电后时间只能保持几分钟到几十分钟。如需长时间断电保持，可加 CR2032 座。

## 墨水屏 — DEPG0420BNS19AF0（4.2寸, 400×300, SSD1619AZ 驱动）

> **颜色：黑白双色，没有红。**（依据：规格书 V2.0 第 5 页「1-bit white and black」；第 6 页光学参数只有黑态/白态，无红/黄项）
> **驱动 IC：SSD1619AZ。**（依据：规格书第 7 页机械图注；命令表 `0x26` 为 Write RAM (Yellow)，属 SSD1619 系列，SSD1680 那颗写的是 RED）
> ⚠️ **面板 RAM 极性：1 = 白，0 = 黑**（命令 `0x24` 说明）。这与固件 framebuffer 的「1 = 黑」**相反**，刷屏时需取反。
>
> ⚠️ **插画的尺寸守卫是“静默跳过”**：`ui_draw_image_full/panel` 发现文件长度对不上（15000 / 3400）时，
> 只 `ESP_LOGW` 然后 `return`。索引指错、文件尺寸不对，都会**画不出图而流程一切正常**。
> 排查这类问题时，先看日志里有没有 `img N size ... skip`。

| 信号 | GPIO | 方向 | 备注 |
|:----:|:----:|:----:|------|
| BUSY | 8 | 输入 | 高=忙 |
| RES# | 2 | 输出 | 低电平复位 |
| D/C# | 3 | 输出 | 低=命令，高=数据 |
| CS# | 4 | 输出 | 低电平选中 |
| SCL | 18 | 输出 | SPI SCK |
| SDA | 19 | 输出 | SPI MOSI（仅写，无需 MISO） |

**SPI 配置：**
- SPI2 外设，全双工主机，模式 0（CPOL=0, CPHA=0）
- 时钟：推荐 2~4MHz（墨水屏内部驱动芯片速度有限）
- 拉高 CS# 后需要等待 BUSY 变低，再发送下一帧

**⚠️ 警告：GPIO18/19 复用 USB JTAG**
- GPIO18(USBD−) / GPIO19(USBD+) 在烧录时由硬件接管下载
- 正常运行时切回 SPI 功能
- **不要在代码中重新配置 USB Serial/JTAG 引脚**，否则会失去下载能力
- 如需强制进下载模式而 USB 失败：GPIO9 拉低 + 复位

**电容清单（软件无关，焊接注意）：**

|:---:|:----:|:----:|:---:|:----:|:----:|
| 5 | VSH2 | 1μF→GND | 20 | VSH1 | 1μF→GND |
| 18 | VDD | 1μF→GND | 21 | VGH | 1μF→GND |
| — | — | — | 22 | VSL | 1μF→GND |
| — | — | — | 23 | VGL | 1μF→GND |
| — | — | — | 24 | VCOM | 0.47μF→GND |

## 蓝牙 — VG6328A（BT/BLE 双模）

| 引脚 | → ESP32 | 备注 |
|:----:|:-------:|------|
| VDD | 3.3V | 上电即工作 |
| GND | GND | |
| TXD | **GPIO 20** | 模块发 → ESP32 收 |
| RXD | **GPIO 21** | ESP32 发 → 模块收 |
| PA9 | **GPIO 1** | 下降沿 → AT 模式 / 唤醒 |

**通信方式：**
- **ClassIsland → VG6328A（经典蓝牙 SPP）** → UART → ESP32
  - 默认波特率 **115200**，8N1
  - ESP32 解析 JSON 格式课表
- **蓝牙键盘 → ESP32 内置 BLE**
  - ESP32 作为 BLE HID Host
  - 键盘按键直接解析，不走 UART

**AT 命令配置（仅初始化时使用）：**
```
GPIO 1 拉低 → 产生下降沿 → 模块进入 AT 模式（100ms 内）
发 AT+NAME=DeskInfo 等配置命令
退出 AT 模式后自动进入透传
```

**数据流注意：**
- UART0 不打印日志，日志走 USB Serial/JTAG
- VG6328A 收发的数据包单包不超过 **255 字节**，分包发送

## 输入 — 五向导航开关（5-way navigation switch）

> 原方案 SIQ-02FVS3 编码器已弃用（滑动开关分不出左右）。详见 `ui-states.md` 第二节、`encoder-arch.md`。

| 开关引脚 | → ESP32 | 外围 |
|:--------:|:-------:|------|
| COM | **GPIO 0** | 100kΩ 上拉到 3.3V |
| 上 | — | 1kΩ → GND |
| 下 | — | 2.7kΩ → GND |
| 左 | — | 5.6kΩ → GND |
| 右 | — | 12kΩ → GND |
| 中央 | — | 22kΩ → GND |

**软件：**
- **一个 GPIO 读出五个动作**：各方向串不同阻值，GPIO0 用 ADC1_CH0 读分压值查表
- 深睡前 GPIO0 配成数字输入 + **EXT1 唤醒**（任意方向按下即拉低）；唤醒后切成 ADC 读方向
- 消抖在软件做（连续采样一致才确认）

**⚠️ 关于 strapping 引脚（已更正）：**
- ESP32-C3 的 strapping 脚是 **GPIO2 / GPIO8 / GPIO9**，GPIO0 不在此列
- 决定启动模式的是 **GPIO9**：上电为低进下载模式，为高进 SPI 启动
- GPIO0 当普通输入用，100kΩ 上拉到 3.3V，按下读低
- 若只用五向开关，原编码器占用的 GPIO9 / GPIO10 可释放

## I2C 总线

| 信号 | GPIO | 上拉 | 挂载设备 |
|:----:|:----:|:----:|---------|
| SDA | **GPIO 5** | 4.7kΩ → 3.3V | DS3231(0x68), MCP3021(0x4B) |
| SCL | **GPIO 6** | 4.7kΩ → 3.3V | DS3231(0x68), MCP3021(0x4B) |

- 标准 100kHz 或快速 400kHz 均可
- I2C 操作在休眠前完成，休眠期间总线空闲

## 深度休眠策略

```
正常使用：
  唤醒 → 读时间(DS3231) → 读电池电压(MCP3021) →
  检查蓝牙是否有新课表 → 刷新墨水屏 →
  设置下一次闹钟(DS3231) → 深度休眠
  总工作电流 ~18μA（休眠态），1000mAh 续航约 32 天
```

**唤醒源：**
- **定时：** DS3231 SQW → GPIO 7（EXT0），用于定时刷新时间/课表
- **用户交互：** 五向导航开关 → GPIO 0（EXT1 唤醒），拨动即亮屏

## 给 Ming 的调试建议

1. **先裸机验证 I2C**：上电先扫 I2C 总线，确认 0x68(DS3231) 和 0x4B(MCP3021) 都在
2. **墨水屏先接杜邦线测试**：不用 FPC，用万用表确认引脚编号无误
3. **USB Serial/JTAG 是首选的烧录和日志口**
4. **首次蓝牙配对需发 AT 命令设名称和波特率**，以后自动连接
5. **电池电压不要上 4.25V**，BQ24073 自动截止，软件读到后做低电量提醒（≤3.4V 通知充电）
6. **SPI 驱动墨水屏前先读 BUSY**，确保空闲再操作

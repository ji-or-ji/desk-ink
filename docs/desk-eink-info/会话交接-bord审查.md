## 二、方法：用网表对账（这是本任务的核心）

单独看新原理图，你没法知道"哪里变了"。但**网表是文本，可以对比**。

仓库里已经有改之前的基线：

```
docs/desk-eink-info/ai-eda-experiment/netlist-v1验证板-Protel2.txt   33 KB
docs/desk-eink-info/ai-eda-experiment/netlist-v2-Protel2.txt         35 KB
```

（2026-09-24 导出的，改动之前的状态。）

**做法**：

1. 用 `tools/netlist-review/export-netlist.ps1` 导出**当前**的网表
2. 跟上面那两份基线**逐行对比**（顺序无关的对比，网表行的顺序不固定）
3. 每一处差异，回到待修清单里找对应项，确认是"修对了"还是"改出问题"

**为什么必须这么干**：`.eprj2` 是 SQLite 二进制，`git diff` 对它完全没用。**网表是唯一能拿来对账的形态。**

## 七、产出

**另有这一轮新加的核查项（2026-10-01）**：

1. **引脚占用的实况。** 从网表里读出**每一根 GPIO 实际接的是什么**，列成表。**不要抄文档里的引脚表**——用户这几天在改图，文档可能已经过期。这份实况是后续引脚规划的依据。

2. **墨水屏 FPC 各脚跟厂商典型电路的核对。** 厂商手册第 8 页是引脚分配表，第 23 页是典型应用电路。重点两件：
   - **第 18 脚 VDD**：厂商的接法是**只挂一颗 1μF 电容到地**（VDD 由 VCI 内部稳压得到），**不接 3.3V**。`eink-arch.md` 里写的是“3.3V + 1μF”，**那份文档可能是错的**，以厂商手册为准
   - **第 9 脚 BUSY**：厂商的典型电路里**没有画上拉**。但它是面板的**输出脚**（手册标的是 O），面板未上电时是高阻；而它接的 GPIO8 是 strapping 脚，**启动时必须为高**

3. **升压电路的元件值核对。** 厂商典型电路给的：R1 = 2.2Ω、Q1 = Si1304BDL、二极管 MBR0530、电感 47μH、电容组 1μF / 1μF / 0.47μF。跟板上实际值对一遍。

4. **两条待定的引脚搬家是否已落地**：
   - 墨水屏 CS# 从 GPIO4 挪到 **GPIO9**
   - DS3231 SQW 从 GPIO7 挪到 **GPIO4**
   （理由：只有 GPIO0 到 GPIO5 能从深睡唤醒，SQW 必须在这段里）

5. 报告里**把“从网表读出来的”和“文档里写的”分开标**。两者不一致的地方就是重点。

厂商手册的页图在 `docs/desk-eink-info/depg0420-docs/`，文件名 `墨水屏-...图片-N.jpg` 对应手册第 N+1 页。

一份 `docs/desk-eink-info/bord-审查/验收报告.md`：

1. **当前网表**跟基线的**全部差异**（列清单，不要只写"有几处不同"）
2. 每处差异的判定：修对了 / 改错了 / 与我无关的其他改动
3. 待修清单 14 条的**逐条状态**
4. **新引入的问题**（如果有）
5. 你**没能确认**的项，以及缺什么信息才能确认

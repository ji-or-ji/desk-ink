### ⬜ 5. BS1 接错电平，面板会进 3 线模式 【已核实】

**现象**：原理图上 `BS1`（FPC 第 8 脚）接在 `VDDIO` / 3.3V 上。

**手册怎么说**（第 11 页表 6-4-1）：

```
BS1 = L   →  4 线 SPI（SDA / SCL / CS# / D/C# / RES#）
BS1 = H   →  3 线 SPI（SDA / SCL / CS#，D/C# 置低）
```

**后果**：按现在的接法，面板会进 **3 线 SPI 模式**。而固件用的是 **4 线**（D/C# 是独立引脚 `GPIO3`）。
**面板不会响应任何命令，整块板白打。**

**怎么改**：`BS1` 接 **GND**（低电平）。不是接 VDDIO。

**额外提醒**：这个错误在 `checklist.md` 和 `progress.md` 里都复制过（已同步改掉），**改动之后全仓搜一遍 `BS1`**，别再漏一处。

### ⬜ 1. I2C 总线与墨水屏 SPI 短接 【已核实】

**现象**：网表里一条网络同时装着 `ESP32-IO18`、`ESP32-IO6`、墨水屏 FPC 第 13 脚、MCP3021 的 SCL、DS3231 的 SCL。

**为什么会这样**：八成是**一个网络标号放错了位置**——`GPIO18` 这个标号落在了 I2C 的网络上，立创EDA 就把两个网络合并了。图上看两条线离得很远，毫无异常。

**怎么改**：把那条错位的网络标号删掉或改对。改完**看网表**确认这两条网络分开。

### ⬜ 2. C6 串在 USB VBUS 与充电 IC 输入之间 【已核实】

**现象**：网络里只有 `U3-13 BQ24073-IN` 和 `C6-2` 两个节点。VBUS 到 IN 之间唯一的通路是那颗电容。

**后果**：电容隔直流，**插 USB 充不进电**。

**怎么改**：VBUS 直连 IN，C6 改成对地电容（`power-arch.md` 要求的就是这个）。

### ⬜ 3. 墨水屏 FPC 第 18 脚 VDD 没接 3.3V 【会话报告】

**现象**：该脚只挂了一颗 C1 到地，没有电源。

**怎么改**：按 `eink-arch.md` 接 3.3V + 1μF。

### ⬜ 4. MCP3021 的 VDD 接了 5V 【会话报告】

**现象**：接到 VBUS（5V），而 `power-arch.md`、`software-notes.md`、`power.c` 都按 3.3V。

**后果**：电池电压读数会**偏低约 34%**——这条直接毁掉省电主线。

**怎么改**：改接 3.3V。

## 2026-10-02 补审（走 EDA 直连，读的是活工程）

> 下面五条是这次新查出来的，前四条独立于上面那批。

### ⬜ 18. `GPIO9` 现在是悬空的 【已核实】

**现象**：`R13`（10K 上拉）删掉之后，`U1-8`（IO9）不属于任何网络。

**为什么要留意**：GPIO9 是 ESP32-C3 的 strapping 脚，启动时需要为高。

**跟现有计划的关系**：墨水屏的 `CS#` 计划从 GPIO4 挪到 GPIO9。**搬之前先定：GPIO9 靠内部弱上拉，还是补一颗外部上拉。**

### ⬜ 19. Type-C 只接了 A 面的数据对 【已核实】

**现象**：`USB1-B6 (DP2)`、`USB1-B7 (DN2)` 不在任何网络里。CC1/CC2 都有 5.1K 下拉，是按标准 Sink 设计的。

**后果**：线缆插反就没有数据连接，跟“支持正反插的 Sink”这个设计意图矛盾。

**怎么改**：`DP1↔DP2`、`DN1↔DN2` 短接。

### ⬜ 20. U5 的电流裕量可能不够 【会话报告】

**现象**：`U5` = XC6206P332MR，额定 300mA。`U1`（ESP32-C3-WROOM-02）标称发送电流 345mA，3V3 上还挂着 MCP3021、DS3231、蓝牙模块和墨水屏。

**要不要处理**：看峰值口径怎么算，值得核一下。

### ⬜ 21. SQW 没有外部上拉 【会话报告】

**现象**：`GPIO7` 上只有 `U1-6` 和 `U4-3 (INT#/SQW)`，没有上拉电阻。DS3231 的 INT#/SQW 是开漏输出。

**跟现有计划的关系**：`SQW` 计划从 GPIO7 挪到 GPIO4。**搬的时候一起定上拉。**

### ⬜ 22. USB 外壳脚悬空 【会话报告】

**现象**：`USB1` 的 `EH`（外壳）脚未连接。常见做法是经电阻或电容接地。

2. 改完 **重新跑一轮审查**——用 `tools/netlist-review/`
3. **重点看它有没有把上次的错都确认掉**。这次审查就是你的验证器
4. 顺便记一下：**这轮脚本一行不改就能跑** → 那就说明该固化成工具了

## 待补：外挂升压电路（漏画，不是错）

**这一条跟上面那些不同**——上面是“画错了”，这一条是“还没画”。所以不排优先级。

它不需要“优先修”，它自己会喊：屏插上去不亮，就是它。也不会偷咬人，一上电就暴露。

真正的要求只有一条：**打样之前补完**——补在打样之后就是重开一版。

### 缺哪几个件

板上已经有升压电容（C4 到 C9），**缺的是功率级**：

| 位号 | 值 | 备注 |
|---|---|---|
| L1 | 47μH | CDRH2D18 / LDNP-470NC |
| Q1 | Si1304BDL | N 沟道 MOSFET |
| D1 D2 D3 | MBR0530 | 肖特基 |
| R1 | 2.2Ω | 0805，1% |

### 连接关系

**升压主回路（产生 VGH）**

```
VCI ──┬── C4（1μF）── GND
      │
      └── L1 ──┬── D3 ── VGH
               │         └── C2（1μF）── GND
               │
               ├── Q1 漏极
               │
               └── C3（1μF，飞跨电容，另一端接 D1/D2 之间的节点）
```

**Q1 的驱动与采样**

```
GDR ──→ Q1 栅极
Q1 源极 ── RESE ── R1（2.2Ω）── GND
```

**产生 VGL 的电荷泵**

```
VGL ──┬── C1（1μF）── GND
      │
      └── D1 ──┬── 中间节点（接 C3 另一端）
               │
               └── D2 ── GND
```

**三颗二极管都指向右**：D3 从开关节点指向 VGH，D1 从 VGL 指向中间节点，D2 从中间节点指向地。
（这一项用户已对着手册复核过。）

### 电容耐压分两档，别混

| 位号 | 值 | 封装 |
|---|---|---|
| C4 C6 | 1μF | 0603，**6V** |
| C1 C2 C3 C5 C7 C8 | 1μF | 0805，**25V** |
| C9 | 0.47μF | 0805，**25V** |

6V 那两颗用在 VCI 附近，25V 那批挂在 VGH / VGL / VSH / VSL 这些高压轨上。**高压轨上放 6V 的电容会炸。**

### 为什么一开始会看漏

`GDR` 和 `RESE` 在引脚表里的描述是“栅极驱动控制”和“电流采样输入”。**只看那一页会以为它们是给面板内部用的，可以悬空。**

但对照典型应用电路（第 23 页）就清楚了：**它们是给外挂这套功率级当控制环的**。

**两页分开看会得出相反结论**——这也是那轮 AI 审查先报后撤回的原因。

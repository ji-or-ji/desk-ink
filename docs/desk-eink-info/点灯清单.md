## 零、开工前（图纸核对，5 分钟）

- [ ] **五向开关的电阻必须是**：上拉 **100k**，方向 **1k / 2.7k / 5.6k / 12k / 22k**
      ⚠️ **这条错了后面全白搭** —— 固件判读阈值就是按这组值写死的（见 `encoder-arch.md`）
- [ ] 墨水屏 24-pin FPC 方向；RES#=GPIO2 / D-C#=GPIO3 / CS#=GPIO4 / BUSY=GPIO8
- [ ] I2C 两条 4.7k 上拉到 3.3V（SDA=GPIO5 / SCL=GPIO6）
- [ ] 万用表量 3.3V 与 GND 之间**不短路**

---

## 一、电源（先不焊主控）

- [ ] 焊电源链路，插 USB
- [ ] 量 XC6206 输出 = **3.3 V ± 0.1**
- [ ] 量 BQ24073 OUT ≈ 电池电压（或 4.2 V）

> 不对就先怀疑焊接/器件方向，别急着往下走。

---

## 二、主控 + 软件栈（**先不接墨水屏、不接开关**）

这一阶段用**两个 Kconfig 开关**跳过外设，避免"一上来就卡死"的排查地狱：

```
idf.py menuconfig
  → Component config → Desk-ink app
      [*] Skip five-way switch init
      [*] Skip e-ink panel init
```

- [ ] 烧写，开串口监视器（**日志走 USB Serial/JTAG，不是 UART0**）
- [ ] **预期**：
  ```
  I main: desk-ink booting
  I store: NVS ready (namespace 'deskink')
  I font: loaded 4037 CJK glyphs + 96 ASCII glyphs
  I app: framebuffer preview (100x30):
  ...
  I app: app started (state=IDLE)
  ```

**走到这里，说明 MCU / NVS / LittleFS / 字库 / UI 渲染全都是好的** —— 剩下的问题必然出在外设。

> `mount failed, (-84). formatting...` 是**正常**的（首次上电会格式化 LittleFS）。

---

## 三、I2C 外设

- [ ] 看 I2C 扫描日志
- [ ] **预期**：`found 0x68`（DS3231）、`found 0x4B`（MCP3021）

> 只出来一个 → 查那个器件的焊接；一个都没有 → 查上拉和总线。

---

## 四、墨水屏

- [ ] 去掉 `Skip e-ink panel init`
- [ ] **预期**：整屏刷新（能看到白/黑翻转），日志里的 ASCII 预览与屏幕内容对应

| 现象 | 大概率原因 |
|---|---|
| 卡在 `eink_init` | BUSY 没响应 —— 查 FPC 座、GPIO8 |
| 有刷新但**整屏反相** | 面板 RAM 极性（**1 = 白**），查刷屏那层的取反 |
| 完全不亮 | 查 VCOM / 升压电容（C4~C9）与 3.3 V |

### 四·补：局部刷新参数标定

整屏能刷之后做这一步。`eink_flush_partial()` 的**几何映射已经确认**（`0x11 = 0x01` 下 Y 递减，规格书位定义证实），但**波形参数 `EINK_PARTIAL_UPDATE_PARAM` 是占位的**，要在这里定下来。

**手上有什么**

| 值 | 出处 | 可信度 |
|---|---|---|
| `0xC7` | 面板手册页 19，LUT 来自 MCU | 手册明写 |
| `0x90` + `0x47` | 面板手册页 19，LUT 来自 OTP（跟随外部温度传感器） | 手册明写，但是**两个值**，可能要分两次写 |
| `0xCF` | 代码里的占位 | **手册里没有**，来源不明 |

**怎么测**

- [ ] 先整屏刷一张**棋盘格**（比纯色更容易看出残影）
- [ ] 局部刷一小块（建议 100×50 的黑矩形），逐个候选值试
- [ ] 每试完一个值，**先整屏刷一次清残影**，再试下一个
- [ ] 都不干净的话，再动 `0x3C` 的 `A[1:0]`（选 LUT0~LUT3）。**已从手册确认**（第 21 页）：`00` = LUT0、`01` = LUT1、`10` = LUT2、`11` = LUT3；上电默认是 **LUT0**，固件用的是 **LUT1**。四套波形都存在面板的 OTP 里，这是选它们的唯一开关。

**记这张表**

| 候选值 | 有反应 | 残影 | 耗时 | 备注 |
|---|---|---|---|---|
| `0xC7` | | | | |
| `0xCF` | | | | |
| `0x90` / `0x47` | | | | |
| `0x3C` = `0x00` / `0x02` / `0x03` | | | | |

**判“够用”的标准有两套，别混**

| 用途 | 标准 |
|---|---|
| Bad Apple demo | 只要有反应、能连刷不卡就够，**容忍残影** |
| desk-ink 日常 | 待办勾选、课表切换要**不闪不脏**，标准严得多，宁可慢 |

> ⚠️ `0x20` 激活**不能中途打断**，否则画面会坏。等 BUSY 的时候别按复位。

## 五、五向开关

- [ ] 去掉 `Skip five-way switch init`
- [ ] 逐个拨：上 / 下 / 左 / 右 / 中央，看日志判读
- [ ] **预期**：方向与拨动一致；中央短按 / 长按能区分

| 现象 | 怎么办 |
|---|---|
| 全是同一个方向，或全是 `ZONE_NONE` | 先量静态电压核对电阻值（回到第零节） |
| 单个方向不对 | 微调 `input.c` 的 `TH_*_MAX`（注释写了按新电阻算） |
| 中央唤不醒（深睡后） | 见 `encoder-arch.md`：这就是要改电阻的原因 |

## 附：为什么分阶段上电

墨水屏的 `eink_init()` 和开关的 `adc_oneshot_new_unit()` 都是**会卡住**的操作
（前者等 BUSY，后者做 ADC 自校准）。一次性全接上，一旦不出图你无法判断是
电源、主控、字库、屏、还是开关的问题。

分三段上，**每一段都把嫌疑范围砍掉一半**。

# 桌面墨水屏信息站 — 硬件模块核对手册

## 1. 电源管理

```
USB-C 5V ──┬── BQ24073RGTR ──┬── XC6206P332MR ── 3.3V ── ESP32 及全部外设
            │                 │
            │                 ├── 分压(100k+100k) ── MCP3021A3T (I2C 0x4B)
            │                 │
            │                 └── 电池保护板 ── 单节LiPo 1000~1200mAh
            │
            └── USB 只充电，系统由 BQ24073 OUT 供电（电源路径管理）
```

**BQ24073RGTR 外围（QFN-16）：**
| Pin | 名称 | 连接 | 值 |
|:---:|:----:|------|:----:|
| 1 | TS | 10kΩ → GND（无 NTC） | 10kΩ |
| 2,3 | BAT | 电池保护板 P+ | 1μF → GND |
| 4 | CE | **GND**（低电平使能） | 直连 |
| 5 | EN2 | GND | EN2=0 |
| 6 | EN1 | 直连 OUT | EN1=1 |
| 7 | PGOOD | → ESP32 GPIO（可选） | 电源就绪指示 |
| 8 | VSS | GND + 热焊盘 | — |
| 9 | CHG | LED + 1kΩ → GND | 充电指示 |
| 10,11 | OUT | XC6206 VIN + 系统负载 | 4.7μF → GND |
| 12 | ILIM | 10kΩ → GND（备用） | 10kΩ |
| 13 | IN | USB-C VBUS | 1μF+0.1μF → GND |
| 14 | TMR | 36kΩ → GND | ≈2h 安全定时 |
| 15 | TD | GND（启用终止） | 直连或 0Ω |
| 16 | ISET | 2kΩ → GND | ≈500mA 充电 |

**EN1/EN2 模式：** EN2=GND (0)、EN1=VOUT (1) → 输入限流 500mA（USB500 模式）

**XC6206P332MR（SOT-23-3）：**
| Pin | 名称 | 连接 |
|:---:|:----:|------|
| 1 | GND | GND |
| 2 | VIN | BQ24073 OUT |
| 3 | VOUT | 3.3V 系统供电 |
- 封装 SOT-23-3（无 CE 使能脚，上电即工作）
- 输出电流 250mA
- 静态电流 6μA Typ
- 输入电容 1μF → GND | 输出电容 1μF → GND

**MCP3021A3T：**
| 引脚 | 连接 |
|------|------|
| VDD | 3.3V |
| VSS | GND |
| VIN | 分压中点（OUT → 100k → VIN → 100k → GND） |
| SCL | I2C SCL（4.7kΩ 上拉） |
| SDA | I2C SDA（4.7kΩ 上拉） |
| 地址 | 0x4B（A3T 版本，内部固定，芯片无外部地址引脚） |

## 3. 双蓝牙

### VG6328A（BT/BLE 双模，替代 HC-05）

| VG6328A 引脚 | 名称 | 连接 | 备注 |
|:-----------:|:----:|------|------|
| 1 | RXD | GPIO 21 (UART0 TX) | ESP32 发→模块收 |
| 2 | TXD | GPIO 20 (UART0 RX) | 模块发→ESP32 收 |
| 3 | GND | GND | |
| 4 | VDD | 3.3V | 上电即工作 |
| 5 | PA9 | GPIO 1 | 下降沿唤醒 + AT 模式 |

- 立创商城编号：C20539408，¥3.89
- 蓝牙 5.3 双模（BT + BLE），ClassIsland 走 BT，键盘走 BLE
- 波特率默认 115200，AT 命令通过串口发送
- 无 EN/STATE 脚，比 HC-05 更简洁

### ESP32-C3 内置 BLE（蓝牙键盘）
- 走 BLE 5.0 HID Host
- 无需额外硬件
- Just Works 配对（免 PIN）

## 5. 五向导航开关（5-way navigation switch）

> 原方案 SIQ-02FVS3 编码器已弃用（滑动开关分不出左右）。需选「四个方向各自独立引出」的型号，避开矩阵式接法。

| 开关引脚 | 功能 | → ESP32 GPIO | 中间电路 |
|:--------:|:----:|:-----------:|---------|
| COM | 公共端 | GPIO 0 | **100kΩ**→3.3V（上拉） |
| 上 | 方向触点 | — | **1kΩ** → GND |
| 下 | 方向触点 | — | **2.7kΩ** → GND |
| 左 | 方向触点 | — | **5.6kΩ** → GND |
| 右 | 方向触点 | — | **12kΩ** → GND |
| 中央 | 中央触点 | — | **22kΩ** → GND |

- 一个 GPIO 读出五个动作：各方向串不同阻值，GPIO0 用 ADC1_CH0 读分压值查表
- GPIO 0 需要外部 100kΩ 上拉到 3.3V。注意 ESP32-C3 的 strapping 脚是 **GPIO2 / GPIO8 / GPIO9**（下载模式由 GPIO9 决定），GPIO0 不在其中
- 深睡前配数字输入 + EXT1 唤醒；唤醒后切 ADC 读方向

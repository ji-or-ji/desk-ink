# 桌面墨水屏信息站 — 项目现状与下一步

> 更新：2026-09-16
> 这份文档的用途是「回到状态」。详细设计见同目录其他文件，引脚以 `gpio-map.md` 为准。

---

## 一、这是什么

一块放在课桌上的 4.2 寸墨水屏信息站。画面常显不耗电，靠电池撑一个月量级。

计划显示：课表、番茄钟、每日一言、新闻、插画、任务清单。

核心思路：**墨水屏断电保持画面 + 主控深度休眠 + RTC 定时唤醒**，把平均功耗压到 ~18μA。

---

## 二、硬件架构

| 模块 | 器件 | 作用 |
|---|---|---|
| 主控 | ESP32-C3-WROOM-02-N4（4MB） | 单芯片 |
| 电源 | USB-C → BQ24073RGTR → XC6206P332MR → 3.3V，单节 LiPo 1000~1200mAh | 电源路径管理 |
| 电量监测 | MCP3021A3T（10-bit，I2C **0x4B**） | 100k+100k 分压测电池电压 |
| 显示 | DEPG0420BNS19AF0（4.2寸 400×300，**黑白双色**，SSD1619AZ，24-pin FPC） | 4 线 SPI |
| 蓝牙 A | VG6328A（BT/BLE 双模） | UART0，收 ClassIsland 课表 |
| 蓝牙 B | ESP32-C3 内置 BLE | HID Host，接蓝牙键盘 |
| 时钟 | DS3231M（I2C 0x68） | SQW → GPIO7，EXT0 唤醒 |
| 交互 | 五向导航开关 | GPIO0 ADC 分压读上/下/左/右/中央 |

15 个可用 GPIO 全部占满，没有余量。

---

## 三、几个当初的设计意图（怕忘，写下来）

- **为什么单芯片**：C3 自带 BLE，能少一颗芯片就少一颗。
- **为什么课表走外挂蓝牙模块**：ClassIsland 从电脑端推的是经典蓝牙 SPP，而 ESP32-C3 只有 BLE，做不了经典 SPP 从机，所以外挂 VG6328A 补这一环。
- **为什么键盘走内置 BLE**：蓝牙键盘是 BLE HID，C3 自己能当 Host，不必再用第二个模块。
- **为什么 RTC + 深睡**：常开撑不了几天，定时唤醒刷一屏再睡才够 30 天量级。
- **为什么用五向开关不用触摸**：省电、省成本、逻辑简单，且一个 ADC 脚读出五个方向。

## 六、踩过的坑（备忘）

- **MCP3021A3T 的 I2C 地址是 0x4B**，不是 0x4D。0x4D 属于 A5T，地址由订购码后缀决定。
- **ESP32-C3 的 strapping 脚是 GPIO2 / GPIO8 / GPIO9**，GPIO0 不是。其中 GPIO9 决定下载模式（原编码器方案曾占用，改五向开关后可释放）。
- **GPIO18 / GPIO19 复用 USB Serial/JTAG**，下载时归 USB，运行时归 SPI 墨水屏。
- **UART0（GPIO20 / GPIO21）被蓝牙模块占用**，日志走 USB Serial/JTAG。
- **IDE 里不要用 CMake Tools 构建**，它会自动套 ARM 工具包，破坏 ESP-IDF 的工具链。用 `Ctrl+Shift+B` 或 ESP-IDF 面板的构建按钮。
- **I2C 旧驱动 `driver/i2c.h` 在 ESP-IDF v6.0 已 EOL**，v7.0 会移除，后续建议迁到 `driver/i2c_master.h`。

# 设计变更请求 — 新增设备端配置页

> 日期：2026-09-17
> **面向：硬件 / 固件会话**（opencode）。只改 `software/`。
> 背景：你已完成 8 个模块骨架（eink / font / input / link / power / rtc / store / ui）。
> 本次新增一个功能，只影响其中一小部分，**不是重做**。

---

## 一、变更概述

设备端新增一个**配置页**，用来就地调整三项参数，省得为了改设置去开电脑。

状态机新增两个 UI 状态：`MENU`（菜单叠加层）、`CONFIG`（配置页）。

---

## 二、需要改的地方

### 1. `components/ui`

新增两个渲染函数：

```c
void ui_render_menu(int cursor);              /* 菜单：番茄钟 / 配置 / 取消 */
void ui_render_config(int item, int value);   /* 配置页：当前项 + 当前值 */
```

### 2. `components/app`（若状态机尚未实现）

按新版 `ui-states.md` 实现，关键差异：

- `IDLE` 下「中央长按」→ 进 `MENU`（不再直接开番茄钟）
- `MENU`：上/下选项，中央短按进入；中央长按 / 左 / 右 = 取消
- `CONFIG`：上/下调项，左/右调值，中央短按保存，中央长按返回
- `POMO` 改为从 `MENU` 进入

### 3. `components/store`

**代码不用改**（NVS 的 API 是通用的，配置项只是不同的 key）。

但请顺手修正 `store.h` 的注释——里面还写着「LittleFS 组件可用性待定，暂未接入」，而 `store.c` 实际已经接好了。

### 4. 配置项 key 约定（NVS，namespace `deskink`）

| 配置项 | 取值 | 默认 | 建议 key |
|---|---|---|---|
| 刷新档位 | 0=自动 1=常规 2=静默 | 1（常规） | `cfg_refresh` |
| 番茄钟专注时长（分） | 15 / 25 / 45 | 25 | `cfg_pomo_focus` |
| 番茄钟休息时长（分） | 5 / 10 | 5 | `cfg_pomo_break` |
| 小窗轮换 | 0=关 1=开 | 1 | `cfg_rotate` |

统一走 `store_get_u32` / `store_set_u32`。

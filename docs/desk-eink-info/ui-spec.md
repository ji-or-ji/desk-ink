# 桌面墨水屏信息站 — UI 规格与刷新策略

> 更新：2026-09-16
> 屏幕：DEPG0420BNS19AF0，400 × 300 横向，SSD1680
> 本文只定"显示什么、在哪、什么时候刷新"。驱动与数据链路见同目录其他文档。

---

## 一、布局

**课表横跨整屏，是顶部的一整条。** 课表下方再分左右两列：左列待办，右列小窗，小窗顶格对齐课表底边。

```
┌─────────────────────────────────────────────┐
│  课 表（横跨整屏）                            │
├─────────────────────────────┬───────────────┤
│                             │  日期          │
│   待 办                      │  ───────────  │
│   （可编辑，仅英文）           │  轮换内容       │
│                             │  新闻/插画/一言  │
└─────────────────────────────┴───────────────┘
         ~266 px                    ~134 px
```

### 建议坐标（400×300，待实物校准）

| 区域 | x | y | w | h |
|------|---|---|---|---|
| 课表长条 | 0 | 0 | 400 | 64 |
| 待办 | 0 | 64 | 266 | 236 |

## 二、区域内容

### 1. 课表长条（横跨整屏）

三行：

- **第一行**：当前课程（节次 + 科目），如「第3节 数学」
- **第二行**：时段 + 总时长 + 剩余时间，如「09:40-10:20 · 共40分 · 剩余约23分」
- **第三行**：下一节课 + 时段，如「下一节 英语 10:30-11:10」

- 数据源：ClassIsland → VG6328A（BT SPP）→ UART → JSON
- 刷新时机：蓝牙收到新课表时；RTC 唤醒时更新节次与剩余时间

### 2. 待办（左下，可编辑）

- 显示：任务清单，每行一条，带勾选框
- 编辑：**本地仅支持英文（ASCII）**，用蓝牙键盘输入
  - 简化理由：免去中文输入法与 CJK 编辑的复杂度
- **中文条目由 PC 推送**（见 `protocol.md` 的 `todo` 消息）；本地勾选 / 编辑的改动会回传 PC
- 刷新时机：**平时静态**，仅在进入编辑、或上下切换勾选状态时刷新
- 编辑状态机：光标上下移动 / 编辑文本 / 切换勾选 / 退出保存

### 3. 小窗（右列，位于课表下方）

分上下两部分：

- **顶部：日期栏（常驻）**
  - 显示当天日期 + 星期，如「2026-09-16 周三」
  - 时间只作粗粒度参考（桌上有钟表），不做分钟级刷新
  - 数据源：DS3231（I2C 0x68）
  - 刷新时机：每次 RTC 唤醒时更新

- **内容区：轮换 / 番茄钟**
  - 默认轮换显示：**新闻 / 插画 / 每日一言**（三选一）
  - 轮换顺序**固定循环**（新闻 → 插画 → 一言）
  - 轮换触发：
    - 自动：每次 RTC 唤醒切换一个
    - 手动：五向导航开关 / 键盘，立即切换
  - **每日一言每天最多更新两轮**，不必频繁拉取
  - **番茄钟运行中：内容区被番茄钟独占**，轮换暂停
  - 刷新时机：轮换切换时；番茄钟运行时按计时粒度刷新

## 三、新闻数据链路（新增）

- 来源：季自维护的 PC 端插件
- 通道：与课表**复用同一条 VG6328A BT SPP 链路**
- 需要协议复用：消息带类型头，例如
  ```json
  {"type": "schedule", ...}
  {"type": "news", ...}
  {"type": "quote", ...}
  ```
- 单包 ≤ 255 字节，超长分包

> ✅ 已定：
> - **每日一言**：ESP32 本地资源，每天最多更新两轮。
> - **插画**：PC 端专用小程序上传/抹除，**预存到 ESP32 本地**（不走实时推送），显示时本地轮换。

## 四、刷新策略与功耗

墨水屏只做必要的刷新，分三类：

| 类型 | 触发 | 范围 |
|------|------|------|
| 整屏刷新 | 首次上电、RTC 唤醒后的页面切换 | 全屏 |
| 局部刷新（小窗） | 轮换切换、番茄钟计时 | 仅小窗内容区 |
| 局部刷新（待办） | 编辑待办时 | 仅待办区 |

**关键点：**

- 静态区（课表、待办）平时不刷新，功耗几乎为零。
- 小窗是独立矩形，**天生适合 SSD1680 局部刷新**，番茄钟倒计时只翻这一块，避免整屏翻转闪烁。
- 需定期整屏刷新一次，清除墨水屏残影（ghosting），频率待实测。

### 番茄钟刷新设计

- 刷新粒度：**粗粒度**（分钟级或仅关键节点），不做逐秒刷新
- 会话时长：默认 25 分 + 5 分休息（可调）
- 局部刷新需单独管理 LUT / 波形，实现比整屏复杂 → 先跑通整屏，再做局部

## 五、字库

**已定：宋体 16×16，GB2312 一级汉字 3755 个 + ASCII 8×16 共 96 个。**

| 用途 | 范围 | 说明 |
|------|------|------|
| 正文（课表 / 新闻 / 一言 / 待办） | 16×16 CJK + 8×16 ASCII | 单套字库，约 127 KB |
| 强调 | 反白（黑底白字） | 不额外占字库空间 |

详细方案、文件格式与生成脚本见 `font-plan.md`。
